Hind Siliguri Font Family (Google Fonts)
---------------------------------------
This folder contains the offline TrueType font files for BaynaChukti:
- HindSiliguri-Regular.ttf
- HindSiliguri-Medium.ttf
- HindSiliguri-SemiBold.ttf
- HindSiliguri-Bold.ttf

Designer: Indian Type Foundry
License: SIL Open Font License (OFL)
Purpose: Ensures 100% offline pixel-perfect Bengali conjunct character rendering (যুক্তবর্ণ ত্রুটিহীন).
